# Алгоритм Хирхольцера

Проект содержит реализацию алгоритма Хирхольцера для построения эйлерова цикла в неориентированном мультиграфе.

## Описание

Программа работает с неориентированным мультиграфом, заданным числом вершин `n` и списком рёбер `edges`.

Эйлеров цикл существует, если выполнены два условия:

1. все вершины ненулевой степени лежат в одной компоненте связности;
2. степени всех вершин чётные.

Если эйлеров цикл существует, алгоритм возвращает последовательность вершин этого цикла. Если цикла нет, возвращается `None`.

## Структура проекта

```text
hierholzer.py
test_hierholzer.py
README.md
```

- `hierholzer.py` — реализация алгоритма;
- `test_hierholzer.py` — юнит-тесты;
- `README.md` — описание проекта и инструкция запуска.

## Запуск тестов

Требуется Python 3.

Для запуска тестов из корневой папки проекта:

```bash
python -m unittest test_hierholzer.py
```

Альтернативная команда:

```bash
python3 -m unittest test_hierholzer.py
```

Ожидаемый результат:

```text

----------------------------------------------------------------------
Ran 7 tests in ...s

OK
```
